================================================================================
USAGE EXAMPLES
================================================================================

Simple usage in Node.js:
```javascript
var alteraparser = require('alteraparser');

var grammar = new alteraparser.Grammar();
grammar.addRule('expr', function(g) {
  return alteraparser.seq(
    alteraparser.tok('NUMBER'),
    alteraparser.many(alteraparser.seq(
      alteraparser.tok('PLUS'),
      alteraparser.tok('NUMBER')
    ))
  );
}, true);

var lexerGrammar = new alteraparser.LexerGrammar();
lexerGrammar.addRule('NUMBER', '[0-9]+');
lexerGrammar.addRule('PLUS', '\\+');
lexerGrammar.addRule('WS', '\\s+', true);

var parser = new alteraparser.TextParser(grammar, lexerGrammar);
var ast = parser.parseText('1 + 2 + 3');
```

Browser usage:
```html
<script src="alteraparser/src/index.js"></script>
<script>
  var grammar = new alteraparser.Grammar();
  // ... set up grammar ...
  var parser = new alteraparser.TextParser(grammar, lexerGrammar);
  var ast = parser.parseText('input');
</script>
```

================================================================================
NOTES
================================================================================

1. Key Implementation Insight:
   The getChildren() method must be used instead of direct property access
   to ensure lazy rule expansion works correctly. This is critical for
   recursive grammar support.

2. No External Dependencies:
   The implementation uses only:
   - Built-in JavaScript features
   - Regular expressions (native to JavaScript)
   - Array and Object methods (ES5 standard)

3. Backtracking Algorithm:
   The parser maintains all valid parse paths simultaneously. This allows
   detection of ambiguous grammars but may be slower for highly ambiguous
   input. For most practical grammars, performance is linear.

4. Grammar State Management:
   Each Grammar instance can only create one syntax graph. If you need to
   use multiple rules as entry points, create multiple Grammar instances
   or use createSyntaxGraphForRule() before parsing.
