Simple Number Parser

This parser recognizes numbers, addition, and subtraction.

Info

AlteraParser is a parser generator that creates ASTs from text input.

Features:

  • Lexer: Tokenizes input text
  • Parser: Builds Abstract Syntax Trees (AST)
  • Grammar DSL: Express grammars declaratively
  • AST Walker: Traverse and transform parse trees
